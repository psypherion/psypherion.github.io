What this is (and isn't)

This is a static site — no backend of mine. All messages and notes are stored in a small Firebase database that anyone with the site's key can read and write to, and everything is broadcast in real time to any browser that has the page open.

Because there's no login, "your" note or message is bound to your browser session. Delete it while you're still on the page, or lose the ability. If you'd like something removed later, the admin can take it down — say the word.

Please be gentle with the room. It's a common space.
